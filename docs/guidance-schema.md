# Repository guidance schema

`AGENTS.md` is the repository operating contract. It is organized into:

1. Role and intent.
2. Operating principles.
3. Execution protocol and routing.
4. Constraints, safety, and lifecycle state.
5. Verification and completion requirements.
6. Marker-bounded runtime and team overlays.

Automation may update only the content inside documented marker pairs. It must
preserve surrounding guidance and may not delete the autonomy directive,
working agreements, safety rules, or verification contract.
